# Product Specification

HamPajuh is a collaborative science and technology platform.

Core modules:
1. User profiles and portfolios
2. Scientific projects
3. Teams and collaboration
4. Git repositories
5. Research data and documents
6. Scientific knowledge hub
7. Collaboration discovery
8. Project showcases

Requirements:
- Persian and English
- Public and private projects
- Verifiable contributions
- Modular scientific disciplines
- Open standards
