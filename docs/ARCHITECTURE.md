# معماری فنی هم‌پژوه

## تصمیم‌های نسخه آغازین
- رابط وب: Next.js App Router و TypeScript
- رابط تعاملی: React
- استایل: CSS مستقل و توکن‌های طراحی
- پایگاه داده هدف: PostgreSQL
- ذخیره فایل‌های حجیم: Object Storage سازگار با S3
- نسخه‌بندی کد: اتصال به موتور Git مستقل
- کنترل کیفیت: GitHub Actions

نسخه فعلی فقط لایه رابط کاربری و داده‌های نمونه را دارد. احراز هویت، پایگاه داده، API، ذخیره فایل و همکاری واقعی هنوز پیاده‌سازی نشده‌اند.

## مرزهای دامنه پیشنهادی
- Identity: حساب، پروفایل، مهارت و اعتبار
- Projects: پروژه، اعضا، نقش‌ها و وضعیت
- Collaboration: وظیفه، بحث، درخواست همکاری و بازبینی
- Artifacts: فایل، داده‌مجموعه، مدل، طراحی CAD و نسخه‌ها
- Research: آزمایش، روش، نتیجه و ارجاع
- Discovery: جست‌وجو، دسته‌بندی و پیشنهاد همکاری
- Trust: مجوزها، سابقه مشارکت و ممیزی

## اصول
1. حوزه‌های علمی به فیلدهای ثابت و محدود در هسته تبدیل نشوند.
2. پروژه یک هسته مشترک و ماژول‌های تخصصی اختیاری داشته باشد.
3. مشارکت‌ها رویدادمحور، زمان‌مند و قابل ردیابی باشند.
4. آثار علمی همراه با فراداده، مجوز، منبع و نسخه ذخیره شوند.
5. فارسی، انگلیسی و RTL/LTR از ابتدا پشتیبانی شوند.
6. فایل‌های حجیم در دیتابیس رابطه‌ای ذخیره نشوند.

## گام بعدی
پیش از اتصال پایگاه داده و احراز هویت، مدل دامنه، مرزهای دسترسی و سیاست نگهداری داده طراحی و بازبینی می‌شوند.
