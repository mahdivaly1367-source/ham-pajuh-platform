# معماری فنی هم‌پژوه

## پشته فعلی
- رابط وب: Next.js App Router و TypeScript
- رابط تعاملی: React 19
- استایل: CSS مستقل با توکن‌های طراحی و فونت فارسی
- پایگاه داده: PostgreSQL
- لایه داده: Drizzle ORM و مهاجرت‌های نسخه‌بندی‌شده
- هویت و نشست: Better Auth
- اعتبارسنجی ورودی: Zod
- کنترل کیفیت: GitHub Actions، TypeScript، Build و آزمون یکپارچه API

## مرزهای دامنه
- Identity: حساب، پروفایل، مهارت‌ها و نمایش عمومی رزومه
- Projects: پروژه، حوزه علمی، سطح دسترسی، اعضا و نقش‌ها
- Collaboration: درخواست همکاری، پذیرش/رد، وظایف و تاریخچه فعالیت
- Artifacts: فراداده فایل، داده‌مجموعه، مدل، طراحی CAD و نسخه‌ها
- Research: آزمایش، روش، نتیجه و ارجاع
- Discovery: جست‌وجو، دسته‌بندی و پیشنهاد همکاری
- Trust: مجوزها، سابقه مشارکت و ممیزی

## اصول معماری
1. هسته پروژه مستقل از رشته علمی باقی می‌ماند.
2. ابزارهای تخصصی به‌صورت ماژول‌های اختیاری توسعه می‌یابند.
3. پروژه‌های خصوصی فقط برای اعضای دارای مجوز قابل مشاهده‌اند.
4. سطح دسترسی در API بررسی می‌شود و مخفی‌کردن کنترل در رابط کاربری جایگزین مجوز سرور نیست.
5. مشارکت‌ها به‌صورت رویدادهای زمان‌مند ثبت می‌شوند؛ ثبت یک رویداد به‌معنای تأیید علمی نتیجه نیست.
6. فایل‌های حجیم در پایگاه داده رابطه‌ای ذخیره نمی‌شوند.
7. فایل‌ها و کدهای ارسالی کاربران به‌عنوان داده غیرقابل‌اعتماد تلقی می‌شوند و در سرور اجرا نمی‌شوند.
8. فارسی و RTL زبان پیش‌فرض رابط است و متن‌های انگلیسی باید در مؤلفه‌های دو‌جهته به‌درستی نمایش داده شوند.

## وضعیت پیاده‌سازی
- هویت، پروفایل، پروژه‌ها، عضویت تیم و درخواست همکاری دارای مدل پایگاه داده و API هستند.
- صفحه کشف پروژه‌ها، فضای شخصی، پروفایل عمومی و جزئیات پروژه پیاده‌سازی شده‌اند.
- مدیریت اعضا و تابلوی وظایف تیم پیاده‌سازی شده‌اند؛ گردش کار وظایف شامل ارسال برای بررسی، درخواست اصلاح، تأیید نهایی و ثبت ممیزی است.
- ذخیره‌سازی باینری، پیام‌رسانی، بازبینی ساختاریافته، اتصال Git و استقرار پایدار هنوز باقی مانده‌اند.
- اجرای CI روی PostgreSQL موقت، صحت فنی مسیرهای آزموده‌شده را بررسی می‌کند و جایگزین استقرار عملیاتی نیست.
