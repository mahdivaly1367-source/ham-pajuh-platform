# راه‌اندازی پایگاه داده

هم‌پژوه از PostgreSQL و Drizzle ORM استفاده می‌کند. اطلاعات ورود با Better Auth مدیریت می‌شود و داده‌های دامنه در جدول‌های PostgreSQL نگهداری می‌شوند.

## آماده‌سازی محیط توسعه

۱. یک PostgreSQL نسخه ۱۵ یا بالاتر راه‌اندازی کنید.
۲. فایل `.env.example` را به `.env` کپی کنید.
۳. `DATABASE_URL` را به رشته اتصال پایگاه داده خود تغییر دهید.
۴. برای `BETTER_AUTH_SECRET` یک مقدار تصادفی اختصاصی با دست‌کم ۳۲ نویسه بسازید.
۵. فرمان‌های زیر را اجرا کنید:

```powershell
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

## متغیرهای محیطی

- `DATABASE_URL`: رشته اتصال PostgreSQL
- `BETTER_AUTH_SECRET`: راز اختصاصی نشست‌ها و توکن‌های احراز هویت
- `BETTER_AUTH_URL`: نشانی اصلی API احراز هویت
- `APP_URL`: مبدأ مجاز برنامه

فایل `.env` و اسرار واقعی نباید به Git ارسال شوند.

## بررسی خودکار

GitHub Actions یک PostgreSQL موقت اجرا می‌کند، مهاجرت‌ها و داده‌های پایه را اعمال می‌کند، TypeScript و Build را بررسی می‌کند و آزمون API را اجرا می‌کند. آزمون API موارد ثبت‌نام، ایجاد پروژه، خصوصی‌بودن پروژه و درخواست همکاری را بررسی می‌کند.

## وضعیت و محدودیت‌ها

- اجرای CI روی پایگاه داده موقت، جایگزین اتصال پایگاه داده دائمی محیط استقرار نیست.
- جدول فایل‌ها فعلاً فراداده و کلید ذخیره‌سازی را نگه می‌دارد؛ بارگذاری فایل باینری هنوز پیاده‌سازی نشده است.
- تأیید ایمیل و بازیابی گذرواژه تا زمان انتخاب سرویس ایمیل فعال نیستند.
- مدیریت اعضا و پذیرش/رد درخواست‌ها در رابط کاربری مرحله بعد ساخته می‌شوند.
- اجرای کد یا فایل‌های ناشناس در سرور هم‌پژوه فعال نیست.

## مهارت‌های پروفایل

مهارت‌های پژوهشگر در جدول مستقل `profile_skill` با ترتیب نمایش و کلید نرمال‌شده ذخیره می‌شوند. شناسه کاربر به پروفایل وابسته است و با حذف پروفایل، مهارت‌ها نیز حذف می‌شوند. مقدارهای تکراری با نرمال‌سازی Unicode و حروف بزرگ/کوچک ادغام می‌شوند.
