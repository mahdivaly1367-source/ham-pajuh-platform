# راه‌اندازی پایگاه داده

هم‌پژوه از PostgreSQL و Drizzle ORM استفاده می‌کند. داده‌های حساب کاربری توسط Better Auth و داده‌های محصول در جدول‌های دامنه نگهداری می‌شوند.

## آماده‌سازی

1. یک پایگاه PostgreSQL نسخه 15 یا بالاتر تهیه کنید.
2. فایل `.env.example` را به `.env` کپی کنید.
3. مقدار `DATABASE_URL` را تنظیم کنید.
4. یک مقدار تصادفی حداقل ۳۲ نویسه‌ای برای `BETTER_AUTH_SECRET` بسازید.
5. سپس اجرا کنید:

```powershell
npm install
npm run db:migrate
```

مهاجرت اولیه در `drizzle/0000_hampajuh_initial.sql` شامل جدول‌های هویت، پروفایل، پروژه، اعضا، درخواست همکاری، آثار پروژه و رویدادهای فعالیت است. حوزه‌های پایه علمی نیز به‌صورت Seed در همان مهاجرت درج شده‌اند.

## متغیرهای محیطی

- `DATABASE_URL`: رشته اتصال PostgreSQL
- `BETTER_AUTH_SECRET`: راز اختصاصی هر محیط
- `BETTER_AUTH_URL`: نشانی اصلی برنامه
- `APP_URL`: مبدأ مجاز برنامه برای نشست‌ها و درخواست‌های احراز هویت

فایل `.env` و اسرار واقعی نباید به Git ارسال شوند.

## وضعیت و محدودیت‌ها

- جدول فایل‌ها فقط فراداده و کلید ذخیره‌سازی را نگه می‌دارد؛ بارگذاری باینری هنوز پیاده‌سازی نشده است.
- ایمیل تأیید و بازیابی گذرواژه تا زمان انتخاب سرویس ایمیل فعال نشده‌اند.
- نقش‌های پروژه در مدل داده وجود دارند؛ صفحه مدیریت اعضا در مرحله بعد ساخته می‌شود.
- اجرای کد یا فایل‌های ناشناس در سرور هم‌پژوه جزو نسخه فعلی نیست.
