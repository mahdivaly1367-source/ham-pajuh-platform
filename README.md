# هم‌پژوه | HamPajuh

**زیرساخت همکاری علمی و فناورانه؛ از ایده تا دستاورد مشترک.**

هم‌پژوه فضایی فارسی‌محور و دوزبانه برای معرفی پروژه‌های علمی و فناوری، یافتن همکار، نگهداری دستاوردها و ساخت رزومه مبتنی بر مشارکت واقعی است.

## اجرای محلی

پیش‌نیاز: Node.js نسخه ۲۰.۹ یا بالاتر و npm.

```powershell
npm install
npm run dev
```

سپس نشانی `http://localhost:3000` را باز کنید.

برای بررسی:

```powershell
npm run typecheck
npm run build
```

## وضعیت فعلی

نسخه نخست رابط کاربری شامل صفحه کشف پروژه‌ها، فیلتر حوزه‌ها، جست‌وجوی محلی و فرم نمایشی ایجاد پروژه است. داده‌ها نمونه‌اند و عملیات فرم‌ها هنوز به سرور متصل نیستند.

## اصول محصول
- پشتیبانی کامل از فارسی و انگلیسی و جهت‌های RTL/LTR
- پشتیبانی از همه رشته‌های علمی و فناوری
- پروژه‌های عمومی و خصوصی
- اعتباردهی شفاف به مشارکت‌کنندگان
- قابلیت بازتولید و ارجاع‌پذیری پژوهش
- معماری ماژولار و قابل توسعه
