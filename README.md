# هم‌پژوه | HamPajuh

**زیرساخت همکاری علمی و فناورانه؛ از ایده تا دستاورد مشترک.**

هم‌پژوه فضایی فارسی‌محور و دوزبانه برای معرفی پروژه‌های علمی و فناوری، یافتن همکار، نگهداری دستاوردها و ساخت رزومه مبتنی بر مشارکت واقعی است.

## امکانات پیاده‌سازی‌شده

- رابط راست‌چین و واکنش‌گرای فارسی
- کشف پروژه‌های عمومی و فیلتر حوزه‌های علمی
- ثبت‌نام و ورود با ایمیل و گذرواژه
- ساخت پروژه عمومی یا خصوصی
- ثبت درخواست همکاری همراه با پیام معرفی داوطلب، پیگیری مدیر پروژه و امکان لغو درخواست توسط متقاضی
- صفحه جزئیات پروژه و فهرست اعضا
- فضای شخصی برای مدیریت پروژه‌ها و پیگیری/لغو درخواست‌های همکاری ارسال‌شده
- ویرایش عنوان، توضیح، وضعیت و سطح دسترسی پروژه توسط بنیان‌گذار
- مدیریت نقش اعضای تیم توسط بنیان‌گذار و ثبت رویداد تغییر نقش
- پروفایل حرفه‌ای قابل ویرایش با مهارت‌ها و ابزارهای تخصصی
- صفحه عمومی پژوهشگر با نمایش پروژه‌های عمومی و فعالیت‌های ثبت‌شده
- مدل PostgreSQL و مهاجرت Drizzle
- آزمون یکپارچه API روی PostgreSQL موقت در GitHub Actions

## راه‌اندازی محلی

پیش‌نیاز: Node.js نسخه ۲۰.۹ یا بالاتر و یک پایگاه PostgreSQL نسخه ۱۵ یا بالاتر.

۱. نصب وابستگی‌ها:

```powershell
npm install
```

۲. ساخت فایل محیطی:

```powershell
Copy-Item .env.example .env
```

۳. مقدارهای `DATABASE_URL` و `BETTER_AUTH_SECRET` را در فایل `.env` تنظیم کنید. برای ساخت Secret تصادفی:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

۴. ایجاد جدول‌ها و داده‌های حوزه‌های علمی:

```powershell
npm run db:migrate
npm run db:seed
```

۵. اجرای برنامه:

```powershell
npm run dev
```

سپس نشانی `http://localhost:3000` را باز کنید.

## کنترل کیفیت

```powershell
npm run typecheck
npm run build
```

GitHub Actions علاوه بر TypeScript و Build، مهاجرت پایگاه داده، Seed و مسیرهای اصلی API را در برابر PostgreSQL موقت آزمایش می‌کند.

## محدودیت‌های نسخه فعلی

- هنوز پایگاه داده دائمی یا هاست عمومی به پروژه متصل نشده است.
- ارسال ایمیل تأیید، بازیابی گذرواژه و اعلان‌ها به سرویس ایمیل نیاز دارد.
- مدیریت اعضا و پذیرش/رد درخواست همکاری در رابط کاربری هنوز ساخته نشده است.
- بارگذاری فایل، فضای ذخیره‌سازی علمی و اتصال Git هنوز در مراحل بعد قرار دارند.
- نمونه‌های صفحه کشف در صورت نبود پیکربندی پایگاه داده، صرفاً داده‌های نمایشی هستند.
